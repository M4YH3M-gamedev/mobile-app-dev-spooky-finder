# mobile-app-dev-spooky-finder
spooky finder assignment

This project uses Figma to create a prototype of a website called 'Spooky Finder', which is a site designed to help users find haunted houses near them.
On the page there is a title and icon at the top to let you know what site you are on.
There is a box at the bottom that is a placeholder for a map in the future.
In between the two is a dropdown menu button, which allows you to select how scary you would like your haunted houses to be.
